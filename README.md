Step to run the program

Extract file
Run Treasure_Hunt_Pangya.exe
How to use program

Put treasure point you want. [Max 10k, Min 0]
Put amount of luck you want. [Max luck factor : 5, Min luck factor : 0]
*Treasure point exceed 1k, natural wind , equipment, cards can increase luck, reward scale diminished for more luck you added.
Press "Drop !" to simulate treasure point drop.
Press "Rate detail" to get drop rate details.
